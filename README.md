# CineApp — Платформа для кинопроизводства

Профессиональное решение для автоматизации съемочного процесса, построенное на базе **Kotlin Multiplatform (KMP)**. Приложение объединяет работу со сценарием, планирование КПП и учет реквизита в единую защищенную экосистему.

## 🚀 Ключевые особенности

*   **Offline-First & Sync**: Полная работоспособность без интернета. Локальная база SQLDelight синхронизируется с Supabase через интеллектуальный `SyncManager`.
*   **E2EE Security**: Сквозное шифрование данных. Текст сценария, заметки и реквизит шифруются на устройстве (AES-256). Ключи передаются между участниками через RSA-обертки.
*   **Интеллектуальный парсинг**: Автоматическое извлечение сцен, персонажей и объектов из PDF-сценариев.
*   **Журнал изменений**: Прозрачный мониторинг действий команды (Activity Log) по всем аспектам проекта.
*   **Адаптивный UI**: Интерфейс на базе Compose Multiplatform, оптимизированный под Desktop (Master-Detail, Three-Pane) и Mobile (Layered layouts).

## 🗺 Архитектура проекта

### 📂 Слой данных (Data & Repositories)
*   `Database.sq` — Определение схемы БД (13 таблиц). Поддерживает версионность, синхронизацию и шифрование.
*   `SyncManager.kt` — Ядро синхронизации. Обрабатывает очередь `SyncQueue`, Realtime-события и разрешение конфликтов по `updatedAt`.
*   `ActivityRepository.kt` — Логирование действий пользователей (загрузка сценария, правки реквизита, управление командой).

### 📂 Безопасность (Crypto)
*   `CryptoManager.kt` — Выполнение операций шифрования/дешифрования и управления ключами.
*   `KeyManager.kt` — Автоматическое управление доступом к проектам: развертывание мастер-ключей и фоновая дешифровка данных.
*   `AuthRepository.kt` — Авторизация и система восстановления ключей по Recovery PIN.

### 📂 Рабочие пространства (Workspaces)
*   `ProjectListScreen.kt` — Главный экран с глобальной статистикой и лентой событий по всей студии.
*   `ScriptWorkspaceScreen.kt` — Управление версиями сценария и диффы между редакциями.
*   `SceneWorkspaceScreen.kt` — Работа с текстом сцены и привязка реквизита "на лету" через интерактивный вьюер.
*   `PropWorkspaceScreen.kt` — Реестр реквизита с двумя режимами: "Склад" и "По сменам КПП".
*   `TrackerScreen.kt` — Оперативный инструмент для съемочной площадки: план на текущую смену.

## 🛠 Технический стек

| Технология | Назначение |
| :--- | :--- |
| **Compose Multiplatform** | Единый UI для Android, iOS и Desktop |
| **SQLDelight** | Типобезопасная локальная БД SQLite |
| **Supabase** | Backend-as-a-Service (Auth, Postgres, Realtime, Storage) |
| **Koin** | Dependency Injection |
| **Kotlinx Serialization** | Работа с JSON DTO |
| **Cryptography (dev.whyoleg)** | Низкоуровневая реализация AES/RSA |

## 📈 Текущее состояние
Проект находится в стадии активной разработки. Реализован полный цикл от импорта сценария до совместной работы над реквизитом с поддержкой E2EE. Все действия команды логируются и синхронизируются между устройствами в реальном времени.
